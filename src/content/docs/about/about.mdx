Saya sedang mengerjakan skripsi dengan tema Urban Sprawl.

Saya ingin menganalisis dampak urban sprawl terhadap kualitas udara, khususnya konsentrasi PM2.5, pada wilayah Kecamatan Semarang Barat untuk tahun 2020.

Tolong bantu saya dengan hal-hal berikut secara LENGKAP dan SISTEMATIS:

1. Jelaskan secara singkat apa itu PM2.5 dan mengapa PM2.5 relevan digunakan sebagai indikator dampak urban sprawl.
2. Jelaskan sumber data PM2.5 yang dapat digunakan untuk wilayah Kota Semarang, dengan fokus pada data tahun 2020.
3. Berikan langkah teknis pengambilan data PM2.5 menggunakan OpenAQ API (versi terbaru), dengan parameter:
   - Lokasi: Kota Semarang
   - Parameter: PM2.5
   - Rentang waktu: 1 Januari 2020 – 31 Desember 2020
4. Buatkan contoh kode Python menggunakan library `requests` dan `pandas` untuk:
   - Mengambil data PM2.5 dari OpenAQ API
   - Mengubah data menjadi tabel
   - Menyimpan hasilnya ke dalam file CSV
5. Jelaskan struktur data hasil unduhan (kolom penting seperti tanggal, nilai PM2.5, lokasi, dan koordinat).
6. Jelaskan keterbatasan data OpenAQ (misalnya resolusi spasial per kota, bukan per kecamatan) dan bagaimana cara menyikapinya dalam penelitian skripsi.
7. Berikan saran bagaimana data PM2.5 tersebut dapat diintegrasikan dengan hasil analisis Kernel Density dan EBK untuk mendukung analisis urban sprawl.
